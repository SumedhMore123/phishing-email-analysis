# Phishing Investigations

This directory contains structured investigations of suspicious email samples.

Each case is documented from a SOC analyst perspective, covering:

1. Incident summary
2. Initial observations
3. Email header analysis
4. Sender and domain investigation
5. URL and attachment analysis
6. Threat intelligence findings
7. IOC extraction
8. Final verdict
9. Recommended containment and remediation

> **Safety:** Do not open or execute potentially malicious attachments or URLs outside an isolated analysis environment. Defang indicators in documentation (for example, `hxxps://example[.]com`).
